# ledweb

локальная панель управления BLE-лентой elk-bledom на этом компе.

    http://127.0.0.1:ПОРТ

## что это

* демон держит ОДНО ble-соединение с лентой постоянно (было: connect+write+disconnect
  на каждую команду — 4 секунды на действие, стало 1–3 мс)
* веб-панель: цвет, яркость, температура, 27 эффектов, сцены, палитры,
  пресеты, расписание по дням недели, таймер, реакция на звук
* rest api + sse, состояние приезжает в интерфейс само
* systemd-юнит с автозапуском

## запуск

    systemctl --user start ledweb
    systemctl --user status ledweb
    journalctl --user -u ledweb -f

руками:

    cd ~/ledweb && ~/.venv_ble/bin/python -m ledweb.main --port ПОРТ

## структура

    ledweb/
    ├── protocol.py    байт-коды, эффекты, палитры, расписание
    ├── driver.py      соединение, очередь, кэш состояния, реконнект
    ├── store.py       пресеты, правила, сцены, настройки
    ├── server.py      http + sse + api (только стандартная библиотека)
    ├── main.py        точка входа
    └── static/        index.html, app.css, app.js, tokens.css, шрифты, lucide

## api

| метод | путь | что делает |
|---|---|---|
| GET | /api/state | текущее состояние |
| GET | /api/meta | эффекты, палитры, сцены, дни недели |
| POST | /api/apply | команда: `{"action":"color","h":270,"s":1,"v":1}` |
| POST | /api/scene | применить сцену по id |
| GET/POST/PATCH/DELETE | /api/presets | свои пресеты |
| GET/POST/DELETE | /api/rules | расписание |
| GET | /api/scan | поиск лент рядом |
| GET | /api/stream | sse с состоянием |
| GET | /api/health | живость |

## горячие клавиши

| клавиша | действие |
|---|---|
| пробел | вкл/выкл |
| 1…9 | пресеты |
| `[` `]` | яркость ±5 |
| ← → | оттенок |
| shift+← → | насыщенность |
| ↑ ↓ | яркость |
| e | эффекты |
| s | сцены |
| t | таймер |
| ? | настройки и хелп |

колесо мыши в любом месте панели меняет яркость.
правый клик по свотчу или по цвету палитры сохраняет его в «мои».

## про варианты протокола

разные прошивки elk отличаются байтом длины и хвостом команды цвета.
в `protocol.py` заведены три варианта: `generic` (len 0x00), `07`, `04`.
если команда не применяется — переключить в настройках, потом рестарт сервиса.

## было раньше

`~/.local/bin/ledctl` — старый cli. он работает, но медленный и с неверной
командой выключения (байт 3 = 0x01 вместо 0x00, то есть off физически
отправлял on). новый драйвер использует корректные коды:

    вкл   7e 00 04 f0 00 01 ff 00 ef
    выкл  7e 00 04 00 00 00 ff 00 ef
